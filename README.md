# Chọn nghề

Website phễu sàng lọc quyết định chọn nghề dành cho học sinh THPT, phiên bản 1.2.

Bốn câu khởi động, bốn ngành gợi ý, đấu trường giữ ngành và bản đồ 11 nhóm. Chạy hoàn toàn trong trình duyệt. Điểm tương đồng thử nghiệm, không phải tỷ lệ chính xác hướng nghiệp.

GitHub Pages: chọn Settings → Pages → Deploy from a branch → main → / (root).

Bản tĩnh chưa có máy chủ thống kê chung hoặc đồng bộ kết quả giữa các thiết bị.
